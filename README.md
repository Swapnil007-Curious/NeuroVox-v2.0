# NeuroVox-v2.0
NeuroVox v2.0 is a conformal 150×50mm forearm wearable PCB. Powered by an ESP32-S3, it captures high-res 4-channel EMG via AD8232, INA333, and ADS1299 ICs using leadless, integrated dry Ag/AgCl edge electrodes. It features a BNO055 IMU for motion artifact rejection, haptics, a 3W speaker, RGB LEDs, USB-C, and a 3000mAh Li-ion power system.
